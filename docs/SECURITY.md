# 安全模型与已知限制

适用对象：`ODIP/0.1.3-exp.1` 本地实验参考实现。只有模拟参与者和合成数据；不得描述为第三方组织接入、真实用户授权、生产安全或互联网认证。

## 信任边界

协议声明、接收端校验、现实事实是三层不同证据。Schema 可验证字段形状；语义层可拒绝 inferred 与 confirmed/satisfied 的矛盾；二者均不能核验用户确实同意、供应商真实存在、引用记录真实、授权有效或交易履行。

参考节点硬编码绑定 `127.0.0.1`，发送端只接受带显式端口的 `http://127.0.0.1` 基址，不跟随重定向、不使用指定中心。使用明文 HTTP 是本机测试传输约定；没有 TLS、证书验证、跨组织信任或机密传输保证。不能把“用了 TCP/IP”或“两进程通过”写成“真实网络安全验证通过”。

身份认证使用配置中的双边随机测试 token，绑定对端 participant_id。消息自报的 sender 必须与配置认证主体一致。每 peer token 至少 32 个 ASCII 字母数字字符，测试在运行时生成；配置文件和数据库不入 Git。该机制验证的是测试密钥持有者，不是组织、个人、Agent 委托或交易资质。

## 实现控制与限制

| 威胁/边界 | 实验控制 | 仍未覆盖 |
|---|---|---|
| 伪造 sender | token 绑定 peer；比较认证主体与 sender | 公钥/证书、真实身份、轮换、撤销、委托链 |
| 越权改需求 | 发布者拥有 update/withdraw/outcome 权限；revision 顺序与撤回终态 | 共同所有权、授权代理、多写者合并 |
| 重复与重放 | SQLite 持久保存 message_id、原始 UTF-8 字节及摘要；同 ID 原字节重复，异字节冲突；事务后回执 | 跨全网唯一性、无限期防重放、跨节点删除同步 |
| 丢回执/断线 | 先存 outbox，再发送；显式 retry 复用相同字节与 ID | 自动调度、退避队列运维、分布式恰好一次处理 |
| 关联混淆 | intent、proposal、receipt 关联与来源/状态检查 | 外部数据库事实、业务合同解释 |
| 不可信 JSON | 65,536 字节上限，深度 32，拒绝重复键、非法 UTF-8、非有限数和畸形 JSON | 完整模糊测试、语言解析器差异分析 |
| 慢请求/资源耗尽 | socket 2 秒、最多 8 工作线程、队列 8、每 peer 每分钟 120 请求；限制编码/长度 | 公网 DDoS、全机隔离、持久数据库容量/磁盘配额、多租户 SLA |
| 私密内容外发 | private 禁止跨节点；selected_participants 仅允许本地显式收件人；不执行聚合分析 | 对方同意证据、数据用途控制、接收后再分享、防重识别 |
| 错误泄漏 | 结构化通用错误码、拒绝原因；运行日志不打印正文/token/异常请求堆栈 | 日志留存审计、端点元数据隐藏、管理员恶意访问 |
| 商业扩展 | 已知 commerce 校验，费率与分账约束；只披露 | 实际授权收费、支付、税务、分账执行、真实重复收费审计 |
| 扩展滥用 | 未知非关键扩展不执行，不修改核心语义 | 全局扩展注册、关键扩展协商、可执行插件沙箱 |

幂等“内容相同”在本传输实验中指完整原始 UTF-8 请求体字节相同。空白、键顺序或数字词法变化也会构成冲突；这不是通用 JSON 规范化算法。发送者必须保存待重试的字节，不能重新序列化后复用同 ID。

`/health` 在回环地址公开进程和模拟 participant 信息，方便测试就绪检查；不应暴露到公网。Python 标准 HTTP 服务用于可读参考代码，不构成经过加固的生产服务器。高并发超过工作线程上限可能直接断开连接，客户端应作为可重试传输故障处理，而非期待每种过载都有协议回执。

## 数据生命周期

数据库保存收到/发出的完整消息和旧 revision，供幂等与原话追溯；撤回意图是业务状态，不等于物理删除。当前没有自动到期、加密存储、备份轮换、远端撤销证明或法定删除实施。仅使用合成数据，不把真实个人信息或实际商业记录输入此原型。

导出通过显式本地 CLI 写新文件，没有未认证的网络导出端点；具有本地文件权限的操作者可读取数据。导出不扩张原始授权范围。操作系统账户、ACL、磁盘加密和备份安全由运行者控制，本次未开展独立 Windows ACL/管理员攻击验证。

## 待独立验证

公网 HTTPS、真实认证授权、密钥管理、防滥用、渗透测试、供应链漏洞审计、跨语言解析一致性、多组织互操作、真实来源证据与隐私法规符合性均尚未验证。第三方独立实现可以使用公开测试集自测，仍需单列其实现、版本、平台和证据；参考实现自测不能替代独立实现互操作。

安全问题仅在本地记录并修复。公开仓库建立后再由维护者配置安全报告渠道，当前不捏造邮件地址、响应 SLA 或已启用的 GitHub 私密通报服务。
