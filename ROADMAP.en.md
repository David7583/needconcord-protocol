# NeedConcord Protocol roadmap

[简体中文](ROADMAP.md) | **English**

1. This experimental release: a publicly readable experimental specification, Schemas, conformance vectors, minimum local implementability evidence and GitHub community materials. The public name is NeedConcord Protocol; the wire identifier remains `ODIP/0.1.3-exp.1`.
2. Community feedback: collect feedback from different domains and independent implementation evidence through Issues, Pull Requests and Discussions. Participation is not certification; feature availability depends on the repository's actual settings.
3. Later RFCs: independent implementation tests across teams and languages, version negotiation, extension registration conventions and more complete representations of authorization and evidence.
4. After a separate security review: HTTPS, identity trust, key rotation, delegated permissions and network abuse testing. Do not deploy the prototype on the public Internet or claim secure interoperability before validation.
5. Investigate discovery, privacy-preserving aggregation, logistics adapters and similar work only when real needs justify it. Payments, commercial platforms and mandatory central services are outside this stage.

A stable release must be supported by public discussion, independent evidence and maintainer review. Passing tests against a single implementation or counting votes is not a substitute.
